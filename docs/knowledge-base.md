## 页面与实训接入

`/courseware/references` 提供四类知识卡、原有文献、关键词检索与分页，原详情地址与引用校验继续使用。每张卡展示教学应用、关联文献、期刊依据与题录来源。

首页保持原对话框，增加训练范围、12个年级、50种家长画像、私聊/电话练习/家长群方式，以及年级示例对应的沟通重点。家校沟通筛选家长角色，综合校园情境保留学生等角色。电话为对话情境，现有语音按钮的可用性取决于设备和语音服务。

五项实训选项同时支持自定义描述（每项1–600字）；描述保存于原`practice-configured`事件的可选`custom`字段，模型提示、评价和复盘共同读取。自定义训练范围使用当前情境已有角色；自定义沟通方式选择基础私聊/电话/群聊范围，原信息权限继续生效。自定义年级投影内置发热情境；其他发布情境保留冻结事实，其自定义描述作为训练背景附加。脚本模式使用安全预设回复。

`POST /api/training-practice` 复用原创建服务，在同一事务写入 `training-created` 与 `practice-configured` 事件；年级、画像和方式随训练保存。再次训练按可信owner读取来源训练，复制设置并创建新训练。原版本记录保留；本次视图从冻结版本与设置事件组合，内置发热情境按选择年级投影文本。自建情境保留其作者定义的年级。

模型对话读取原角色可见事实与设置事件。家校沟通筛选家长回复，电话使用口语交流提示，群聊提示词使用公开事实，个体私密事实和隐含披露内容保持隔离。角色输出继续经过原泄露扫描，消息、状态推进、幂等和模型失败处理沿用。

`GET /api/training-practice/[id]/support` 通过原owner服务读取当前训练的有效消息与事件。辅助反馈从消息派生；助教检索待复核措辞，提供参考说法和知识卡链接。完整一轮计为一条学员发言获得一条角色回复，未回复发言和重复角色回复不额外计轮。

助评每10轮展示一组阶段反馈，五维分别列出可复核行为线索、待复核措辞与原消息证据。关键词和规则具有覆盖范围限制，界面标明反馈方法。正式五维评分继续通过原模型评价、JSON解析、消息ID证据校验与持久化服务生成，助评阅读提示作为背景接入该提示词。
